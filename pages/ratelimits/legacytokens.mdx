## Legacy Tokens

<Callout type="error">Legacy tokens are no longer supported. Any request that uses one is rejected with a `403`. Please [log in](https://some-random-api.com/user/settings) and generate a new token.</Callout>

---
Legacy tokens were issued before the current token system and reached the end of their life in July, 2026. They no longer grant any access, whether or not the account has premium.

A legacy token is handled exactly like any other invalid token. The request is **rejected**, it is not treated as an unauthenticated request, and you will receive a `403` with the following body:

```json
  {
    "error": "Invalid or expired token. Please generate a new token from the dashboard at https://some-random-api.com/user/settings."
  }
```

### Moving to a new token

1. Log in to the [SRA Dashboard](https://some-random-api.com/user/settings).
2. Generate a new token.
3. Send the new token in the `Authorization` header instead of your legacy token. See [Authorization](/authorization).

Your new token uses the standard [ratelimits](/ratelimits/tokens), and it is the only kind of token that can use premium perks.
